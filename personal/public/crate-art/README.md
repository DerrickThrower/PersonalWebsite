Sleeve photos go here.

Reference them from the RECORDS array in ../crate.html:

    art: "crate-art/antalmanac.png"

Square images look best — the sleeve is 1:1, and anything else is
centre-cropped to fill. The photo is scrimmed dark automatically so the
catalogue number and org still read over it. Omit `art` and the record
keeps its procedural groove cover.
